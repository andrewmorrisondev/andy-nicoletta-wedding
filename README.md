# Nicoletta & Andy wedding site

A static wedding website with no dependencies. Keep `portrait.jpg` alongside
`index.html` when publishing.

## Finish
The names, date, venue, and dress code are set. Update the schedule, travel
details, FAQ, and RSVP section once those plans are confirmed. The RSVP section
does not yet submit to the Google Sheet.

## Run locally
Just open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080

## Deploy
Works as-is on Vercel, Netlify, GitHub Pages, Cloudflare Pages, or any static host.
